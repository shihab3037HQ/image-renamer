    How it works

    1. Your listPaste or upload Style, Colour, Size and ASIN for every child product. Copy them from your Amazon listing file.
    2. Your photosDrop one folder with a subfolder for each colour, or for each style with its colours inside. Each size gets its colour's photos.
    3. CheckSee every new file name, style by style, plus anything Amazon may reject: wrong ASINs, missing folders, small or unsupported photos.
    4. DownloadGet one ZIP for Amazon, a ZIP for each style, or folders to look through first. A report comes with it.

    How to set up your photo folder

    Make one folder for each colour. Name each photo with any word, a dot, then the Amazon code. The tool swaps the first word for each ASIN. Photos named just MAIN.jpg or PT01.jpg work too.

    More than one style (or parent)? Make a folder for each style, with its colour folders inside, and add a Style column to your list. Two styles can both have Black: each one keeps its own photos, its own group in the check and its own folder or ZIP in the download.

    A single folder for a style and colour, like Style 1 Black, works too. Capitals, spaces, dashes and underscores in folder names don't matter.

    Selling single products without colours or sizes? Choose Folders named with ASINs and name each product's folder with its ASIN.

    Amazon image file names, the short rules

    For Amazon's bulk image upload, every file name is the product ID, a dot, the image code, then the file type: B0XXXXXXXX.MAIN.jpg.

    PartWhat to use
    Product IDThe ASIN, or the UPC, EAN, ISBN or JAN, with no spaces or dashes
    MAINThe main image: the product on a pure white background
    PT01 to PT08The other images, in the order shoppers see them
    SWCHThe swatch shown when shoppers pick a colour
    File typeJPEG (best), PNG, TIFF or GIF. Not WebP or HEIC
    SizeAt least 1,000 px on the longest side so zoom works, at most 10,000 px

    A name with extra characters, like B0XXXXXXXX.MAIN (1).jpg, is skipped by Amazon. Rules can change: check Amazon's image requirements in Seller Central.

    Upload the ZIP to Amazon

    1. In Seller Central, open Catalog, then Upload images.
    2. Open the bulk image upload tab and choose your ZIP file.
    3. Amazon checks the photos, which can take a while. Check the upload status on the same page, and fix any rejected files.

    Questions

    Are my photos uploaded anywhere?

    No. The tool runs in your browser. Your photos are read on your computer and never uploaded, and your original files are never changed.

    How should I name my photos?

    Any word, a dot, then the Amazon code, for example photo.MAIN.jpg, photo.PT01.jpg or photo.SWCH.jpg. Files named just MAIN.jpg or PT01.jpg work too. Other codes in your names are kept, and the check tells you if Amazon may not accept them.

    Can I use an Excel file?

    Yes. Upload an .xlsx or .csv file with Style, Colour, Size and ASIN columns, or copy the rows from Excel and paste them. Style is only needed when you have more than one. .

    What if two styles have the same colour?

    Add a Style column (a column named Parent works too) with each style's name, for example Style 1 and Style 2, and keep each style's colour folders inside a folder with that name. The check shows every style on its own, and tells you if two of them use the same photos.

    Can I look at the photos before I make the ZIP?

    Yes. After the check, choose In folders, to check first. You get a folder for each style, colour, size and ASIN. When they look right, choose One ZIP for Amazon and download: no need to check again. If you changed the folders by hand, drop them back in with Folders named with ASINs.

    Is there a limit?

    No set limit. Big jobs are split into ZIP files under 1 GB and 1,000 photos each, the safer limits for Amazon's upload. In Chrome and Edge you can also save the photos straight into a folder.

    Does it check the white background?

    Not yet. It checks names, ASINs, file types and photo sizes. Amazon checks the main image background when you upload.
